Privacy Policy

Last updated: 2026-10-28

Claude MCP is used only by its owner, Vinicius Noronha, on his own computer, to access his own Gmail accounts.

  • Data accessed: Gmail messages, labels and basic settings of the owner's accounts, through the Gmail API scopes he authorizes.
  • Storage: OAuth tokens are stored only on the owner's local machine. No server operated by this app stores Gmail data.
  • Sharing: Gmail data is not sold or shared with third parties. It is only processed locally to fulfil the owner's own requests.
  • Google API Services User Data Policy: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revocation: access can be revoked at any time at https://myaccount.google.com/permissions.
